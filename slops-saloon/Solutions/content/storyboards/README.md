# Storyboards

Beat-by-beat visual plans for tier 3+ videos — bridges a script (`../scripts/`) to production
(assets, voice, edit). One storyboard per video in production.

Storyboard fidelity is one of the six dimensions `slops-content-ship` checks at
`short-video-workflow.md` step 8 — the finished cut's beat order should match what's filed here.
