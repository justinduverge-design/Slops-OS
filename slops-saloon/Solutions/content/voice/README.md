# Voice

Working notes on VO for in-progress videos — chosen voice profile, generation notes, anything not
already captured by `slops-voiceover`'s own output.

**The actual generated audio files do not live here.** Per `slops-voiceover`'s Output Contract, real
VO audio lands next to the consuming Remotion project, e.g.
`omen/Brand/promos/omen-coming-soon/public/audio/vo/*.{wav,mp3}`. This folder is for planning/notes
only — which preset was used and why, take notes, pacing concerns to flag before generation.

Current voice preset is being changed from "Onyx" to a more feminine option — see
`Direction/current_sprint.md` D2 and `Blueprints/specs/omen-character-spec.md` §3.
