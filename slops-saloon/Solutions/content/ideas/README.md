# Ideas

Raw, uncommitted content ideas — one file or one line per idea, whatever's fastest to capture.
This is `short-video-workflow.md` step 1 ("Capture idea"). Nothing here needs to be polished or
even usable yet; the bar is just "written down somewhere findable."

An idea graduates out of this folder when it's picked up at step 2 (Decide format) and a script
gets started in `../scripts/`.

See `Direction/content-strategy.md` for the content goals and OK-to-joke-about list ideas should
draw from.
