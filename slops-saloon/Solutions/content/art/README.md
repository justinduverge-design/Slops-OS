# Art

Static art assets used across content — not UI screenshots (those are captures, see the note
below), but drawn/generated art: Omen character art, backgrounds, quote-card templates, recurring
world backdrops (League Court, Waiver Wire Tavern, etc.).

Real product UI screenshots used inside a composition live with the consuming Remotion project
instead, e.g. `omen/Brand/promos/omen-coming-soon/public/captures/` — don't duplicate those here.

No dedicated art tool is set up yet (see `Blueprints/specs/content-tool-stack.md` §4 — Krita/GIMP/
Inkscape/Blender are optional, unused as of 2026-07-14). Flag if a video actually needs original art
so the tool question gets resolved against a real need instead of speculatively.
