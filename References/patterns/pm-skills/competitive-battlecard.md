# Competitive Battlecard

Create a concise, sales-ready battlecard against a specific competitor: `$ARGUMENTS`.

## Context

Web-search the competitor's current product, pricing, positioning, and recent changes. If files are provided (feature lists, win/loss data, sales call notes), read them first.

## Instructions

1. **Research** (web search): offerings/features, pricing tiers & model, target market/positioning, recent launches, known strengths/weaknesses, review sentiment (G2, Capterra, Reddit).
2. **Build the battlecard**:

   ### Company Overview
   Founded, HQ, funding/revenue (if public); target market/ICP; one-sentence positioning.

   ### Quick Comparison
   | Capability | Us | Them | Winner |
   |---|---|---|---|
   | [Feature area] | [Our approach] | [Their approach] | Us/Them/Tie |
   | Pricing | … | … | … |
   | Support | … | … | … |

   ### Where We Win
   - [Advantage]: [proof point / customer quote / capability they lack].

   ### Where They Win
   - [Their strength]: [our counter-positioning / how we mitigate].

   ### Common Objections & Responses
   | Prospect Says | Respond With |
   |---|---|
   | "Competitor X has [feature]" | "[Our alternative + why it's better for them]" |
   | "They're cheaper" | "[TCO / ROI / hidden costs]" |
   | "They're more established" | "[Speed, innovation, focus, support]" |

   ### Landmines to Plant
   Questions that highlight competitor weaknesses: "How important is [area we excel] to your team?", "Have you evaluated [capability they lack]?"

   ### Win/Loss Patterns
   We win when: [pattern]. We lose when: [pattern]. Key differentiator: [what tips the scale].

3. **Keep it scannable** — reps reference this mid-call. Tables, bold, short bullets. Save as markdown.
