# Patterns Index

Layer 0 (SLOPS) research patterns. Each file distills reusable findings from research and critic review into patterns the company can apply across projects. These are inputs to decisions and specs, not decisions themselves.

## How to use

Read a pattern file when starting work in its topic area to avoid re-deriving what research already settled. When a pattern hardens into a standing rule, capture it as a decision in `Direction/decisions/` and reference it from the relevant spec.

## Naming convention

Pattern files use hyphen-case: `topic-patterns.md`. (Older underscore drafts have been normalized; superseded raw drafts live in `Archive/superseded-patterns/`.)
