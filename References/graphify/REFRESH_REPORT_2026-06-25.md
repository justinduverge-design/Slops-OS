## Carryover

Cross-layer edges (L0↔L2 in particular) are the high-value bridges this refresh was meant to surface. `merge-graphs` cannot create them; only `graphify update` against a single combined working tree can. Next refresh should:

1. Stage L0, L1, L2 source roots under a single staging folder (Windows `mklink /J` junctions are sufficient; no admin needed).
2. Run `graphify update <staging>` once to produce a single graph.json where the extractor sees all three layers as one tree, so a markdown link from `omen/CLAUDE.md` → `../../Blueprints/agent-modules/identity-claude.md` produces a real edge.
3. Aim to re-establish the 2026-06-21 L0↔L2 edge count (27) as a floor.

Until then, the canonical graph is honest at the node level and intra-layer edge level, but does **not** answer "which OS doctrine silently constrains an Omen module" by graph traversal.
