## Evidence 2 — Local Claude enforcement rules

`C:\Users\JDuve\.claude\settings.json` carries **no** permission rules — only UI and
model preferences (`theme`, `effortLevel`, `tui`, `autoUpdatesChannel`,
`enableWorkflows`, `agentPushNotifEnabled`, `skipWorkflowUsageWarning`).

`C:\Users\JDuve\.claude\settings.local.json` carries all 11 permission rules. This
confirms the P3 prerequisite: the 15 → 11 reduction holds, and 11 is what is live.

```json
"allow": [
  "Bash(npm --prefix frontend run build)",
  "Bash(npm test *)",
  "Bash(npm run *)",
  "Bash(npx vite *)",
  "Bash(curl -s -o /dev/null -w \"%{http_code}\" http://localhost:5173/)",
  "Skill(gstack)",
  "Skill(gstack:*)",
  "mcp__notebooklm-mcp__notebook_list",
  "mcp__notebooklm-mcp__notebook_get",
  "mcp__notebooklm-mcp__notebook_describe",
  "mcp__notebooklm-mcp__source_describe"
]
```

| B12 sub-check | Verdict | Evidence |
|---|---|---|
| No blanket **publication** access | **PASS** | No rule permits push, publish, post, send, deploy, or any outbound write. The four `notebooklm` rules are all read verbs (`list`, `get`, `describe`). |
| No **indirect executor** access | **PARTIAL — see finding** | `Bash(npm run *)` is the exception. |

**Finding (B12.1): `Bash(npm run *)` is a standing indirect-executor grant.** `npm run`
executes whatever the target `package.json` defines, so a script named `deploy`,
`migrate`, `release`, or `publish` would run pre-approved under a rule that reads as a
harmless build allowance. The specific rule `Bash(npm --prefix frontend run build)`
immediately above it is the correctly-scoped form — the wildcard makes it redundant and
broader than intended.

This is precisely what the runtime trust model forbids: a standing grant that survives
task boundaries and does not depend on an Active Trust Assignment.

| Item | Path |
|---|---|
| `Bash(npm run *)` | **A — enforce now.** Replace the wildcard with the explicit scripts actually needed (the `--prefix frontend run build` rule is the pattern). |
| `Bash(npm test *)` | **B — time-boxed exception.** Test execution is non-destructive in this repo today. Owner: founder. Expiry: next cutover review. Re-verify no `pretest`/`posttest` hook gains side effects. |
| `Bash(npx vite *)`, `curl` localhost probe, `Skill(gstack*)`, 4 × notebooklm reads | **No action.** Bounded, read-only or local-dev-only. |
