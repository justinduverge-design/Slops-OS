# Reviews Index

Layer 0 (SLOPS) review records. Two kinds live here: critic reviews of OS projects before a decision is locked, and import reviews that assess external agent divisions before any of their agents are promoted into the active roster.

## How to use

Reviews are evidence, not authority. They inform decisions (`Direction/decisions/`) and agent promotion, but a review on its own does not change the system. Imported agents named in these reviews are not active until wrapped and indexed in `Blueprints/agents/AGENT_INDEX.md`.
