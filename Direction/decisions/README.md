# Decisions Index

Layer 0 (SLOPS) decision records. Each file captures a company-level decision: the question, the options weighed, and the chosen direction. Treat these as the standing answer until a newer decision supersedes them.

## How to use

When a decision here conflicts with something in a spec, prompt, or review, the decision record wins unless Justin says otherwise. New decisions should be added as their own file and linked here.

## Decisions

| File | Decision |
|---|---|
| `app-strategy-decision.md` | Direction for app/distribution strategy (PWA vs native and related strategy questions). |
| `design-md-decision.md` | Adoption of the canonical `design.md` template and the `design-md-author` skill workflow. |
| `slops-os-dbs-decision.md` | The DBS (folder system) routing model and skill-creation approach for SLOPS OS. |
| `slops-os-markdown-decision.md` | The Markdown operating package: how SLOPS context/markdown files are authored and normalized. |
