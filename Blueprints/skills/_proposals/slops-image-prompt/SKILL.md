# Slops Image Prompt (PROPOSAL)

## When to Use
Need a prompt for any image-generation tool (DALL-E, Imagen, Midjourney, SDXL local, etc.). Pairs with the future `share-hash-og-image` skill.

## Scope
Produce a structured image-gen prompt: subject, composition, palette (pulled from brand-system.md), style references, negative constraints, target aspect ratio, and per-tool prompt syntax notes. Output is prompt text only — no images are generated by the skill.

## Required Inputs
- Asset purpose (OG card, hero image, trade-share thumbnail, etc.).
- Brand palette + voice anchors.
- Target tool (SDXL local preferred per sovereignty).

## Outputs
- Markdown block with the prompt + per-tool variants + negative-prompt block.

## Does NOT
- Generate the image.
- Approve final assets.
- Bypass `slops-ux-copy` for any text-in-image.

## Replaces / Complements
- Replaces candidate agent `design-image-prompt-engineer`.
- Complements future `share-hash-og-image`.

## Verification
- Smoke: the prompt produces a result that matches the brand palette without manual touch-up.
