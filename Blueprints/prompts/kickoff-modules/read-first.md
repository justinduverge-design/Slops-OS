# Read First (kickoff-specific)

Before running pull-task, you've already read your wrapper's Always-read 5-file set. Don't re-read them.

Additionally read on demand:

- The `Blueprints/specs/*` spec referenced in the sprint item (e.g., `page-system.md` for any Phase 1.4–1.12 frontend work)
- The relevant handoff (`backend-to-frontend.md` for frontend work; `frontend-to-backend.md` for backend work)
- The recent commits if the task is a continuation (`git log --oneline -20`)

Do not pre-load archives, old prompts, or worktree copies. The current files are authoritative.
