# Resources Index — Pointer

**Canonical:** `Blueprints/RESOURCES_INDEX.md`

That file aggregates everything available to you:

- **Skills** — `Blueprints/skills/SKILL_ROUTING.md` (read the Status column first; legend at the top of the file)
- **Tools** — `Blueprints/tools/TOOLS_INDEX.md` + `Blueprints/tools/tool-permissions.md`
- **Agents** — `Blueprints/agents/AGENT_INDEX.md` (only wrapped agents are live; `_imported/` is dormant)
- **Prompts** — `Blueprints/prompts/` (runnable instructions, kickoffs, command bridges)
- **MCPs / Plugins / Connectors** — runtime list available via ToolSearch (`ToolSearch { query: "..." }`)

**Rule:** before claiming a capability doesn't exist, check the index. Before inventing a new approach, check if a skill already covers it.
